# JanuaPort

Der self-hosted MCP-Gateway für den Mittelstand: die eine Tür, durch die KI an interne Systeme darf —
fein berechtigt, protokolliert, im Haus.

**Was hier offen liegt (Apache 2.0):**

- [januaport-integrations](https://github.com/JanuaPort/januaport-integrations) — Connector-Beschreibungen und ihr Format
- [januaport-clients](https://github.com/JanuaPort/januaport-clients) — Anbindungen für KI-Clients
- [januaport-plugins](https://github.com/JanuaPort/januaport-plugins) — Zusatzdienste neben dem Gateway
- [januaport-recipes](https://github.com/JanuaPort/januaport-recipes) — Rezepte für wiederkehrende Abläufe
- [januaport-deploy](https://github.com/JanuaPort/januaport-deploy) — Vorlagen für den Betrieb
