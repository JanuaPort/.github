# JanuaPort

**English** · [Deutsch](#deutsch)

The self-hosted MCP gateway for mid-sized businesses: the one door through which AI may reach internal
systems — finely permissioned, logged, in-house.

**Open here (Apache 2.0):**

- [januaport-integrations](https://github.com/JanuaPort/januaport-integrations) — connector specs and their format
- [januaport-clients](https://github.com/JanuaPort/januaport-clients) — connections for AI clients
- [januaport-plugins](https://github.com/JanuaPort/januaport-plugins) — companion services next to the gateway
- [januaport-recipes](https://github.com/JanuaPort/januaport-recipes) — recipes for recurring workflows
- [januaport-deploy](https://github.com/JanuaPort/januaport-deploy) — templates for operation

The core — sign-in, permissions, vault, pseudonymisation, audit log — is a product of JanuaPort GmbH.
It is free for up to three seats. Pricing and terms (in German): https://januaport.ai/preise

Found a vulnerability? security@januaport.ai — see https://januaport.ai/.well-known/security.txt
